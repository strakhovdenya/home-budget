## План одного узкого изменения

1. **«Остатки».** Подписать X «Дата проверки», Y «Остаток, EUR»; добавить читаемые даты, денежные деления и лёгкую сетку. X пропорционален календарным интервалам, Y — фактической сумме. Читаемый диапазон Y строится по минимуму/максимуму показанных фактических значений с небольшим визуальным отступом, без принудительного включения нуля; границы явно подписаны. Пустая выборка, одна точка и одинаковые суммы не ломают масштаб. Рядом с графиком обязательно видны точная сумма с центами и полная дата последней показанной проверки (последней в существующем порядке), без hover или выбора. При пустой выборке — отсутствие проверок, не нулевая сумма. Краткая подпись «Проверки на этой странице» обозначает границу ряда.
2. **Режим показа.** По умолчанию «Только точки». Предложение для ревью: переключатель «Соединить проверки» добавляет прямые отрезки только между фактическими соседними точками текущей страницы в существующем порядке; маркеры остаются. Только при включённой линии видна подпись «Между проверками остаток неизвестен»; подробное пояснение доступно рядом с переключателем. Нет сглаживания, аппроксимации, расчёта/подсказок промежуточных сумм, продолжения к H/концу месяца или через границу страниц. При одной точке линии нет. Проверки одной даты не соединяются, если точное время хотя бы одной из них неизвестно: разрыв не обходится соединением через пропущенную точку. Даже при известном времени соединение одной даты допустимо лишь при доказанном различимом времени обеих проверок и согласованном существующем порядке; время/порядок не выводятся из ID или порядка сохранения. Исходные порядок и координаты не меняются. REPORT остаётся карточкой последней проверки и отдельным endBalance/UNKNOWN, без искусственного ряда.
3. **Точные значения и выбор.** На desktop hover показывает дату и точную сумму точки, click открывает детали; на mobile tap открывает закреплённую рядом с графиком карточку деталей с закрытием. Для совпадающих/плотных точек крупная область нажатия сначала раскрывает список фактических проверок с датами/суммами; выбор строки открывает детали конкретной проверки, без сдвига координат и потери записей. Ни hover, ни открытие деталей не выбирают проверку для сравнения и не запускают запрос сравнения. «Выбрать для сравнения» — отдельное явное действие в деталях или существующей строке/карточке; только оно использует прежний read-only путь сравнения двух проверок. Исходные строки/карточки и сравнение остаются доступны.
4. **«Месяцы».** Сохранить группированные, не составные столбцы. Добавить видимую легенду с теми же цветами и полными названиями: A — «Распределено», R — «Полные резервы», S — «Накопления», F — «Свободно». X — финансовые месяцы; Y — EUR, единая линейная шкала для всех четырёх серий всей выбранной выборки месяцев, нулевая линия и несколько числовых делений/линий сетки. Для локальных окон использовать всю уже загруженную выборку `page.months`, не только видимые группы; при перелистывании локального окна границы/деления Y не меняются и одинаковая сумма имеет одинаковую высоту. Не догружать данные ради шкалы; изменение фильтра или серверной страницы означает другую выборку. F ниже нуля сохраняет знак; R/S не изображаются обеспеченными частями A. При достаточном пространстве показывать точные числовые подписи столбцов без наложений; если они не помещаются — не уменьшать текст до нечитаемого размера. Hover показывает месяц, показатель и точную сумму с центами; click/tap открывает карточку с этими данными, на mobile она закреплена до закрытия/смены выбора. У нулевого столбца тоже есть область выбора. UNKNOWN не превращается в столбец нулевой высоты; существующие точные таблицы/карточки и сообщение о дефиците сохраняются.
5. **Mobile, темы и подписи.** При 320/375px сохранять нормальный размер текста и высоту графика, сокращать только число делений, переносить легенду. Для месяцев показывать небольшое локальное окно групп с кнопками «Предыдущие / Следующие», без сжатия всех месяцев в узкую SVG и без дополнительных запросов. Кратко обозначать видимый диапазон; единый масштаб всей выбранной выборки сохраняется при перелистывании. Оставить постоянно видимыми необходимые оси/деления, легенду, диапазон, последнюю показанную проверку и финансовые статусы; не повторять служебные пояснения у каждой точки/группы. Подробные предупреждения сохранять в соответствующем контексте: режим линии, сравнение (разница не есть доход/расход), REPORT/UNKNOWN и дефицит. Полные даты/суммы доступны по tap и в карточках. Подсказки не выходят за экран; без горизонтального overflow страницы, перекрытий и обрезанных минусов/валюты. RU/DE/EN, light/dark; SVG-текст наследует актуальный цвет темы.

## Acceptance criteria — 5

1. В «Остатках» видны оси и читаемая шкала Y по фактическому диапазону без принудительного нуля; точная сумма и дата последней показанной проверки обязательны без hover. Каждая реальная проверка доступна с точной датой/суммой. Default — только точки; предложенные отрезки требуют решения Q-HB22-R3-01, не дают промежуточных остатков и не соединяют проверки одной даты с неизвестным точным временем.
2. В «Месяцах» цвет связан с полным названием A/R/S/F; единая числовая шкала EUR всей выбранной выборки не меняется между локальными окнами, сохраняет ноль и отрицательный F. При достаточном пространстве видны точные подписи столбцов; по выбору на mobile открывается точная карточка, включая нулевые значения. UNKNOWN и дефицит отображаются честно.
3. Hover показывает значение, click/tap открывает детали, сравнение выбирается только отдельным действием. Совпадающие точки сначала раскрывают список фактических проверок. Открытие/закрытие деталей не меняет сравнение; детали не перекрывают нужные controls.
4. При 320/375/1280px во всех RU/DE/EN × light/dark читаемы необходимые подписи, суммы и легенда; постоянный служебный текст не дублируется, контекстные предупреждения доступны там, где нужны. Нет overflow, clipping или overlap; все данные доступны через график/локальное окно и существующие таблицы/карточки.
5. Read-only и исходные данные сохранены; изменены только разрешённые UI/i18n/new-test hunks. Существующие тесты и keyboard/семантика сохранены. Проверки и независимое ревью имеют фактическое evidence; исторический PASS не выдаётся за R3 PASS.

## Тесты — 7 групп, все NOT EXECUTED

1. **Точки/масштаб:** 0/1/несколько проверок; неравные интервалы дат, одинаковые суммы, реальный ноль, крупные суммы и центы, узкий ненулевой диапазон (например, 770–800 EUR). Y охватывает фактические значения с отступом без принудительного нуля, позиции пропорциональны. Последняя показанная проверка имеет точную дату/сумму без hover/выбора; при смене страницы подпись обновляется, при пустой выборке не показывает ноль. Данные и точные суммы не меняются.
2. **Режимы:** default без линии; включение/выключение отрезков и контекстного предупреждения, отсутствие выдуманных точек/подсказок между проверками, соединений страниц и REPORT-ряда. Две проверки одной даты с неизвестным временем хотя бы одной не соединяются, разрыв не обходится; равное известное время тоже не даёт различимого порядка для линии. Новый тест дополняет неизменённую старую проверку default без `path/polyline`; проверки opt-in относятся только к отдельно утверждённому режиму.
3. **Выбор проверок:** hover, click/tap деталей и их закрытие не меняют сравнение и не вызывают actions; совпадающая/плотная группа сначала раскрывает список, строка открывает детали каждой фактической проверки. Отдельное «Выбрать для сравнения» сохраняет прежние ID и read-only запрос двух проверок; выбор строки списка сам по себе сравнение не запускает.
4. **Месяцы:** все четыре серии, соответствие цвета/названия/суммы, положительный/нулевой/отрицательный F, R+S>A, все нули, UNKNOWN и крупные суммы. Ноль выбирается, signed F ниже нуля; при перелистывании окон с резко разными суммами границы/деления Y и высота одинаковых сумм неизменны. При достаточном месте точные подписи видны, при недостаточном не перекрываются; mobile tap открывает карточку точного месяца/показателя/суммы с центами.
5. **Локальное состояние/read-only:** режим, hover, открытие/закрытие деталей и окна месяцев не вызывают actions и не меняют basis/query/данные; только отдельное действие сравнения использует прежний запрос. После смены страницы/H/K/REPORT старые подсказки исчезают. REPORT/UNKNOWN/loading/error/retry и вкладка funding проходят неизменённые UI-регрессии.
6. **Реальный браузер:** 320/375px с touch и 1280px с мышью × RU/DE/EN × light/dark; обычный и плотный наборы, обязательная последняя проверка без hover, детали отдельно от сравнения, подписи столбцов/точная mobile-карточка, стабильный масштаб локальных окон, краткие постоянные подписи и контекстные предупреждения, controls, ошибки/retry, отсутствие overflow. Визуально осмотреть скриншоты, а не считать DOM-проверку доказательством читаемости. Отдельные WCAG/ARIA/скринридер/zoom200%/OS-theme suites не добавляются (D62).
7. **Регрессия/границы — новая авторизация владельца D64:** новый UI-тест и непосредственно связанные неизменённые analytics UI/comparison tests; scoped TypeScript и ESLint по затронутым файлам без fix; Code Quality Hooks, проверка diff/неизменности protected paths и self-review двумя code-quality skills только по новым/прямо изменённым TS/TSX hunks. Выборочная реальная браузерная QA: 320/375px touch и 1280px mouse, несколько представительных RU/DE/EN × light/dark, плотные точки и отрицательный F, осмотр фактических скриншотов. Этот scope заменяет прежний план полного локального `pnpm test` и finance/scenario gates: полный app/finance/PostgreSQL прогон, полная браузерная матрица и специальные accessibility-проверки не требуются и без отдельного технического основания не запускаются. Пункт 6 теперь применяется к выбранным сочетаниям, не ко всем комбинациям. Полный CI будущего PR остаётся обязательным. Старые тесты/исторические результаты не переписывать; отдельная оценка читаемости обязательна. Недоступную среду/проверку явно записать, не заявлять PASS.
