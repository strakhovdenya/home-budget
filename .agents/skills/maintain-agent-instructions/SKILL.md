# Maintain Codex harness instructions
1. Read AGENTS.md, docs/AGENT_FACTORY.md, docs/CODEX_WORKFLOW.md, architecture, business rules and conventions.
2. Identify duplicates, misplaced details, missing pointers and contradictions in AGENTS.md.
3. Move domain rules to docs/BUSINESS_RULES.md, code rules to docs/conventions.md, architecture to docs/ARCHITECTURE.md, build commands to docs/PROJECT_CONFIG.md.
4. Keep AGENTS.md a concise, high-signal router with the **critical financial invariants** and security warning.
5. Never silently delete an instruction; describe change and show original intent retained in linked documents.
6. Verify skill paths exist; do not create CLAUDE.md or .claude/ by default.
