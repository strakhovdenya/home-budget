# Create milestone / roadmap
1. Read AGENTS.md, docs/PRODUCT.md, docs/BUSINESS_RULES.md, docs/ARCHITECTURE.md and docs/ROADMAP.md.
2. Identify incremental deliverables preserving checkpoint-first finance and full reserves. Risk and prerequisites before UI.
3. Propose numbered phases with goals, bounded scope, verifiable exit criteria, dependencies and excluded work.
4. Edit docs/ROADMAP.md **without erasing agreed decisions**. Keep Phase 0 documentation and Phase 1 finance-engine priority.
5. If GitHub CLI authenticated and user authorizes remote edits, inspect existing milestones then create only missing ones. Otherwise write milestone drafts to docs/ROADMAP.md.
6. Report which parts are proposals vs remote artifacts created; never claim milestones exist without checking.
7. Do not initiate Claude pipeline or install godark; this is a Codex workflow skill.
